## 🧠 核心设计哲学

我的设计思考可以概括为：

> **从“线性传导”到“生态演化”**  
> 无论是历史模拟还是 AI 系统，真正有趣的东西都不是被设计出来的，是从无数个微小互动里“长”出来的。

> **把“文化基因”翻译成代码**  
> 我做的每个项目，本质上都是在试图用代码捕捉一种“无形的力量”——比如《周易》的占卜逻辑、AI 的记忆层、游戏里的历史变迁。
